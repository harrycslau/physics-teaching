Raybox Bench – Help

Ray Box

  • Drag the ray box to move it; drag the rotation handle (circle) to rotate it.
  • Use the Power button to turn the beam on/off.
  • Use None / Single / Triple to switch slit attachments.

Placing Components

  • Click a component button in the toolbar to place it at the bench center.
  • Drag the component body to move it.
  • Drag the rotation handle (circle above the component) to rotate it.
  • Click to select; press Delete key or the 🗑 Del button to remove.

Properties Panel

  • Shows position, rotation, focal length (lenses), or refractive index.
  • Lens focal length is editable — type a value and press Enter.

Keyboard Shortcuts

  • Ctrl+Z – Undo
  • Ctrl+Y – Redo
  • Delete / Backspace – Delete selected
  • Escape – Deselect
